
StormBPMN Enterprise {{ .Chart.AppVersion }} развёрнут (чарт {{ .Chart.Name }}-{{ .Chart.Version }}).

1. Дождитесь готовности подов (первый старт с миграциями БД — до 5 минут):
     kubectl --namespace {{ .Release.Namespace }} rollout status deployment/{{ include "stormbpmn.fullname" . }}

2. Откройте приложение:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  {{- range .paths }}
     http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
  {{- end }}
{{- end }}
{{- else if and .Values.httpRoute.enabled .Values.httpRoute.hostnames }}
{{- range .Values.httpRoute.hostnames }}
     https://{{ . }}/
{{- end }}
{{- else if contains "NodePort" .Values.service.type }}
     export NODE_PORT=$(kubectl get -n {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" svc/{{ include "stormbpmn.fullname" . }})
     export NODE_IP=$(kubectl get nodes -o jsonpath="{.items[0].status.addresses[0].address}")
     echo "http://$NODE_IP:$NODE_PORT"
{{- else if contains "LoadBalancer" .Values.service.type }}
     kubectl get -n {{ .Release.Namespace }} svc -w {{ include "stormbpmn.fullname" . }}
{{- else }}
     kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "stormbpmn.fullname" . }} 8081:{{ .Values.service.port }}
     # затем откройте http://127.0.0.1:8081
{{- end }}

3. Активируйте лицензию (новая установка):
   a) Откройте /admin-onboarding (вход не нужен), скопируйте весь код активации.
   b) Передайте код менеджеру StormBPMN и получите LICENSE_KEY_V2 для этой инсталляции.
   c) Передайте ключ: --set storm.license.keyV2=... или ключ LICENSE_KEY_V2 в existingSecret,
      затем helm upgrade.
{{- if .Values.existingSecret }}
      При existingSecret поды сами не перезапустятся — после правки Secret выполните:
        kubectl -n {{ .Release.Namespace }} rollout restart deployment -l app.kubernetes.io/instance={{ .Release.Name }}
{{- end }}
   d) Создайте первого администратора в мастере настройки.
   Подробно: https://enterprise.stormbpmn.com/operation/License.html

4. SSO (Keycloak, Azure AD, ADFS) настраивается в админ-панели /app/admin.

Проверка: helm test {{ .Release.Name }} --namespace {{ .Release.Namespace }}

          curl http://127.0.0.1:8082/actuator/prometheus
{{- end }}

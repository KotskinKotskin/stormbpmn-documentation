## ✨ New features {#✨-новые-возможности}

- The simulation summary now includes a what-if scenario map: you can visually compare different process variants and see how changes affect the results.
- Simulation reports can be published via a link: it is convenient to share modeling results with colleagues and management without granting access to the entire diagram.
- The profile now allows you to delete your account yourself if you no longer plan to use the service.
- The chat now features a "Coach" mode: the system first helps clarify the task and context, and then proposes an action plan for process improvement.
- The planner and "scouting" in the chat now take the entire dialogue into account, not just the last message, making recommendations more accurate and consistent.
- A daily quota has been introduced for the free tier in the AI chat, with a clear notification and an upgrade offer — you can see the limit in advance and plan your usage.
- A mobile version has been added to the admin panel: key settings can now be conveniently viewed and changed from a phone.
- A widget grid module has been introduced: interface elements can be freely dragged and arranged in a layout that suits you.

## 🚀 Improvements {#🚀-улучшения}

- Diagram and label visualization in the designer has been improved: labels and element highlights are now more predictable and readable.
- Public sharing of simulation reports and the quota for shared diagram access now work consistently and are more transparent for users.
- The text editor interface (Tiptap) has been refined: pop-up panels and overlays no longer cover unnecessary elements or interfere with text editing.

## 🔧 Fixes {#🔧-исправления}

- Account security has been significantly strengthened.
- After a password change, the system no longer "throws" you to the login form, and the verification of the current password and account status now works correctly.
- Access to diagrams is now correctly accounted for in the sharing quota: deleted diagrams do not occupy space in the limit.
- The document conversion system correctly distinguishes between a situation where the service is temporarily unavailable and a simple timeout, which reduces the number of "unclear" errors for users.

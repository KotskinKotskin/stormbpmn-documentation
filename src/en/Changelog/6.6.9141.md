## ✨ New Features {#✨-новые-возможности}

- **Home page: "My Views", "Needs Attention", and "Resume Work".** The home page now displays your key views, tasks awaiting decisions, and processes you can easily return to with a single click — less time spent searching, more time working.  
- **Full-screen AI chat with history.** A dedicated AI chat page has been added, making it convenient to run long sessions, return to past dialogues, and use the chat as a permanent process assistant.  
- **"Agentic cycle" interface in AI chat.** The work plan, "coach," and quick replies help solve complex tasks step by step: you can see exactly what the AI is doing and manage the workflow.  
- **Group permissions for diagram folders.** You can now set access for user groups at the diagram folder level, simplifying permission management in large teams.  
- **New simulation list: hypothesis tree and "Favorites".** The simulation list displays hypothesis branches as a visual "graph," allowing you to quickly switch between scenarios and mark important simulations with a star in a separate tab.  
- **"Recent" diagrams with a "In Tree" transition.** The recent diagrams block now includes a compact card and an "In Tree" button that highlights the relevant branch — making it easy to return to work in the right context.  
- **"Test Hypothesis" button in simulations.** A completed simulation can be quickly "cloned" and launched as a new scenario without reconfiguring everything from scratch.  
- **Saving diagram edits in simulations.** Changes on the BPMN canvas are now saved directly in the simulation configuration, ensuring the process model and calculation scenario always match.  
- **Auto-fill of full name when logging in via SSO/OAuth2.** When authenticating through a corporate provider, the system automatically populates the user's first and last name, reducing manual input.  
- **Session binding to SSO.** The system session is now correctly extended through your SSO provider, reducing unexpected account logouts.  
- **Wiki: protection against circular embeds and fragment unbinding.** You cannot accidentally embed a page into itself or create a "circular" structure, and embedded fragments can be cleanly unlinked from the source page.  
- **Wiki: clear access and "no permissions" state.** If you lack access to a page, you see a clear state and message instead of an "unknown error."  
- **Wiki: publish only when a draft exists.** The "Publish" button appears and functions only when there is actually content to publish, eliminating confusion.  
- **Wiki: new content width.** The text area width is now adaptive (80% of the screen), making long documents more comfortable to read.  
- **AI user retention engine.** A new AI module has been added to the system for analyzing and generating retention scenarios (currently in safe mode with no impact on live data).  
- **Case simulations on the showcase.** Real simulations and a separate showcase of calculated scenarios are now used for 42 demonstration cases — helping you better understand how the product works with live examples.  
- **What-if explanations for scenarios.** Explanations of "What this means" have been added for 48 simulation scenario types, helping business users interpret results without analyst assistance.

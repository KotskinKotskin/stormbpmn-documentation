## ✨ New Features {#✨-новые-возможности}

- An AI assistant is now available in the right sidebar: it helps you understand the diagram, formulate requirements, and refine processes directly while you work.
- AI chat history with sessions has been added: you can return to previous discussions, continue them, and avoid losing important hints.
- The admin panel now allows you to select the AI model provider and format (OpenAI / DeepSeek / Anthropic) "on the fly," enabling you to flexibly configure the quality and cost of hints for your company.
- A post-login hint screen has been introduced for free teams with multiple users: it helps you understand the additional benefits of upgrading to a paid plan.
- The feedback module now features flexible access rights and tab-based filters: you can more precisely control who sees and fills out what, and find the needed answers faster.
- Survey invitation sending has been added: you can invite specific colleagues to complete surveys without granting access to everyone.
- Custom request flow scheduling is now available in process simulation: you can set intensity by day and time to model real load peaks and troughs.
- A new "by schedule" option for custom user intensity has been added: it is convenient for setting presets and quickly switching between scenarios.
- The CRM module now supports issuing corporate invoices on behalf of a client: this simplifies work for partners and integrators managing multiple companies.
- Invoices and billing now support corporate payment on behalf of a client and improved license management: it is easier to control who can register and within what limits.
- The "Contact Sales" form now passes an anonymous identifier: this helps the sales team better understand the source of the request without disclosing personal data.
- OAuth 2.1 support has been added for integration with external AI connectors: this makes connecting custom AI services more secure and convenient.

## 🚀 Improvements {#🚀-улучшения}

- The AI chat interface has become more convenient: response formatting rules, the session list appearance, and the assistant's system behavior configuration have been improved.
- The default interface language is now Russian until other languages are fully translated, which reduces confusion for new users.
- Working with tables and text in the wiki has become closer to the familiar Notion experience: improved table resizing handles, active cell highlighting, header toggling, block backgrounds, quotes, and the table of contents.
- Navigation in the wiki has become more intuitive: the table of contents, hover behavior, display of multi-line items, and visual highlights have been refined.
- The wiki editor has become visually more stable: "flickering" during the rendering of formulas and embedded blocks has been removed, and the operation of pop-up menus and the ESC key has been improved.
- The appearance and context menu of the BPMN editor have been updated, and "reactive" tooltips over elements have been added: working with the diagram has become simpler and more intuitive.
- Bulk role assignment in BPMN now correctly ignores elements to which roles do not apply, reducing the risk of accidental errors during large-scale changes.
- Navigating event connections in read-only mode has become more convenient: element focus and selection now behave predictably.
- Diagram export via PlantUML has become cleaner: images are no longer cropped and correctly adjust to the size.
- Invoice cost calculation has become more responsive: the number of unnecessary recalculations when changing the number of participants, months, and entering the INN has been reduced.
- Licenses are cached and better controlled: the system checks limits faster and prevents registration beyond the paid limit.
- Working with the org structure and assignee assignment has become more reliable: cascading changes to roles and positions are handled correctly.
- The interface for transferring administrator rights within a team has become clearer and more error-resistant.
- Registration and authorization via Yandex have become more secure: the exchange of authorization codes for tokens has been moved to the server side.  

## 🔧 Fixes {#🔧-исправления}

- Improved the ownership transfer and recipient selection form: the current user no longer disappears from the list.  
- Fixed rare errors when dragging processes in the registry: moves are now always saved correctly.  
- Improved drag-and-drop behavior for processes: the system correctly handles transfers without data loss.  
- Removed unnecessary requests in invoices when entering the taxpayer identification number (INN) and changing parameters — the form no longer lags or stutters.  
- Refined filters and data loading for surveys in the registry and BPMN editor: eliminated hangs and pending requests.  
- Fixed specific scenarios related to survey access rights: individual rights now correctly override general ones, and users without access see appropriate messages.  
- Resolved issues with displaying and hiding tooltips and overlays in the BPMN editor, including during complex element modifications.  
- Fixed errors in the wiki editor related to deleting quotes, background highlighting, tables, and the table of contents, which could lead to unexpected behavior during editing.  
- AI chat history and chat title generation now work correctly in all modes, including integrations with external connectors.  
- AI streaming responses have become more stable: resolved interruptions and delays related to buffering.  
- Fixed specific issues with A/B tests and experiment initialization to ensure all users are correctly assigned to the intended interface variants.  
- Improved the stability of migrations and database operations in rare configurations to ensure updates run without failures.

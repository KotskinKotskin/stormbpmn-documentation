## 🚀 Improvements {#🚀-улучшения}

- In the interface with a large number of elements (highly "branched" trees, hierarchy lists), navigation and display have been improved to make working with large structures easier and more intuitive.
- In the service header, the display of the notification icon has been improved: the new notification indicator is now always neatly positioned and does not overlap the icon.
- The team color scheme is now correctly preserved when switching between different sections, ensuring that the team's brand color is not "reset" and the interface appears more cohesive.
- A convenient scrollbar has been added to the employee table, simplifying work with long lists and making navigation through employees more comfortable.

## ✨ New Features {#✨-новые-возможности}

- A new **"Diagram"** tab has been added to simulation reports, featuring a node heat map, overlays, and task markers. This allows you to visually identify process "bottlenecks" directly on the diagram and more quickly pinpoint areas for improvement.
- A new **"Resources"** tab has been added to simulation reports, providing detailed analytics: resource utilization, operating modes, idle time, and activity summaries. This helps you understand who is overloaded, where personnel or equipment are idle, and how to redistribute the workload.
- A new **"Lean Six Sigma"** tab has been introduced, featuring a maturity dashboard and visual indicators. You can now assess process maturity using the LSS approach and track improvement progress.
- **Multi-select** functionality has been added to custom fields for entity-related fields. You can now flexibly describe objects (processes, tasks, resources, etc.) by selecting multiple values instead of just one.
- Process search now considers the **process code** (e.g., P2P.1.2) and process type, and utilizes enhanced text search. Finding a specific process by its internal code and description is now simpler and more accurate.
- The wiki now supports **restoring previous versions**, lazy loading of the section tree, and batch processing of attachments. This facilitates working with extensive documentation and reduces the risk of losing important edits.
- For accounts with automatic license issuance disabled, an **activation pending** mode has been added. New users can register and await approval without disrupting the current licensing policy.
- The login screen now features a **live BPMN background and a marketing headline**. The new visual style better communicates the product's value to new users.
- In the cases section, the **"Tell us about your case"** button now directs users to a case study page rather than an external messenger. This makes knowledge sharing more transparent and convenient.
- The marketing section of the site now implements **cross-linking between Stormverse, Registries, and BPMN elements**, and SEO URLs have been updated. Users can more easily navigate between examples, reference materials, and notation elements, and find relevant content via search.
- The website gallery now includes a **lightbox, image download, soft crop, and a "View All" button**. Presentations and process examples are now easier to view and share with colleagues.

## 🚀 Improvements {#🚀-улучшения}

- Process search has become smarter: data freshness has been improved when schemas change, a combined search mode (vector + classic) has been added, and results are now more relevant to business queries.  
- Simulation reports are now more intuitive: task overlays have been improved, a compact mode has been added, important elements can be "pinned," chart cards have a unified style, and legends for thresholds are cleaner — analyzing simulation results is now easier even without deep technical knowledge.  
- The "Resources" tab in reports has received a redesigned section layout, unified importance tones, and summary totals — key resource insights are now visible at a glance, without lengthy table analysis.  
- The wiki interface is now clearer: when navigating to a non-existent page, a "page not found" state is explicitly displayed, and outdated drafts have an indicator and an update button — this reduces confusion during collaborative work.  
- The login screen and authorization process have become more convenient: an unnecessary consent checkbox has been removed for enterprise clients, error handling and activation waiting states have been improved, and resubmitting the form via Enter no longer interferes with login.  
- Team invitation handling has become more reliable: email-based permissions are correctly accounted for, team membership is not lost, and invitees are not considered active participants until confirmation — this helps manage license seats more accurately.  
- In user fields, when re-editing, **the default value is not reset** — card and form settings are preserved predictably.  
- Interface texts and translations (including declensions, route headings, diagram elements, and registry items) have been improved in Russian, English, and German — the interface is now more consistent and understandable for international teams.  
- Marketing pages (home, gallery, presentations, articles) have received an improved dark theme, clean client logos, enhanced navigation, and accessibility — product materials are easier to read and present to clients.  
- Stormverse integration has been improved: diagrams open on the first click, the address in the link and state during transitions are correctly accounted for — navigation through process examples has become more stable.  

## 🔧 Fixes {#🔧-исправления}

- Improved role assignment handling on the diagram: "role ↔ element" links are no longer displayed outside the current diagram body, reducing unnecessary "noise" and misunderstandings when analyzing responsibility.  
- Fixed boundary event behavior in BPMN diagrams: incorrect links from corner boundary elements into shapes are no longer created, reducing the risk of logical errors in models.  
- Resolved issues in simulation reports related to canvas errors, legend boundaries, and element accessibility — reports now open more reliably and display correctly even on complex models.  
- Fixed global wiki search via Ctrl+K — knowledge sections are now correctly displayed in the general search panel.  
- The wiki now correctly extracts fragments even from unpublished drafts, and if version issues occur, the page does not remain "empty" — this reduces the risk of content loss.  
- Improved the stability of opening diagrams and applying user overlays on first open — display settings are no longer "lost".  
- Fixed specific issues with the gallery on marketing pages (disappearing elements, "holes" in the grid, missing files, captions, and lightbox localization) — material viewing is now predictable and free of visual artifacts.  
- Resolved rare errors in authentication related to simultaneous form submission, autofocus, and error handling — system login is now more stable even with an unstable connection.

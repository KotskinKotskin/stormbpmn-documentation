## ✨ New Features {#✨-новые-возможности}

- BPMN diagram flow analysis is now available: the system helps identify potential issues in process logic during the modeling stage and improves its quality.  
- A business process quality scoring service has been added: you get a more visual quality metric for the model and can track improvements from version to version.  
- In the process registry, you can now update existing records during import, add descriptions, and link processes to the required objects — this simplifies maintaining a unified process catalog.  
- The process editor now includes a "Simulation" entity and a simulation status indicator — making it easier to understand which models are ready for execution and what stage the analysis is at.  
- A direction type has been added for asset relationships — this allows for a more precise description of how objects interact with each other.  
- Marketing blocks with large images now support video insertion, providing more options for visually presenting processes and solutions.  

## 🚀 Improvements {#🚀-улучшения}

- The export interface has been updated: exports now run asynchronously with clearer notifications and a refreshed appearance, making it more comfortable to work with large data dumps.
- Process import has been improved: changes are correctly rolled back when the operation is canceled, and the procedure itself has become more reliable and predictable.
- The process registry interface has been improved: smoother tree loading, no "flickering" during updates, preservation of selected filters, and neat dropdown lists even with long names.
- A convenient scrollbar has been added to the diagram version list, simplifying navigation through a long change history.
- The org structure interface has been improved: freezes during loading and updating have been fixed, and changes are displayed faster and more stably.
- Approval counters have been restored in the personal menu, and authors and editors can now resubmit approval requests — this speeds up work with documents and reminders.
- Avatar display has been corrected in the user profile, and support for custom photos has been added, making the interface more personalized.
- The appearance, syntax highlighting, and link handling have been improved in the wiki editor and text fields, and a dark theme has been added for the editor — reading and editing text has become more convenient, including in the dark interface.
- The process quality indicator has been improved: the display has become more intuitive, making it easier to assess the state of the process model "at a glance."
- Multilingual interface support (Russian, English, German) has been improved in the registry and other sections: translations have become more consistent and polished.  

## 🔧 Fixes {#🔧-исправления}

- Improved process import behavior: if the operation is canceled, data is not partially committed to the system, and the state is reverted to its original condition.
- Fixed issues with selecting assignees and roles: removed duplicate employees and restricted role selection to only those available to the process model author.
- Eliminated redundant requests and errors during page refresh in the process registry; the process tree no longer breaks in dark mode or disappears during loading.
- Removed edit buttons and calls to action from the diagram viewer and diagram table for users with read-only permissions to prevent a misleading interface.
- Removed the "Unavailable" block from the sidebar for anonymous users to make the panel cleaner and more intuitive.
- Fixed issues with PDF export (duplicate pages and notifications) and the display of payment data in CloudPayments.
- Corrected visual inconsistencies in marketing pages and the interface dark theme to ensure a uniform appearance.

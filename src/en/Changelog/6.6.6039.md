## ✨ New Features {#✨-новые-возможности}

- A process simulation results panel with key performance indicators (KPIs), process "health," and a 2×2 KPI grid has been introduced — making it easier to identify bottlenecks and understand where the process performs worst.  
- A visual "health" indicator for simulation results with sub-scores has been added — allowing you to quickly assess the overall process state and drill down into details when needed.  
- Simulation launch, status tracking, and re-runs are now available directly from the interface — enabling faster scenario execution and result comparison.  
- A new table with a "summary ↔ flat list" toggle has been added to the diagram view — facilitating the analysis of large models and quick location of specific elements.  
- Auto-saved versions in the process version history are now displayed by default — simplifying rollbacks to a desired state without manual searching.  
- A tree view for pages has been added to the Wiki — making the knowledge base structure more intuitive and section navigation easier.  
- Bulk operations (add, update, delete) are now available for Wiki blocks — speeding up major documentation edits and reducing the risk of errors.  
- Previous diagram versions can now be restored via the AI chat and through MCP — making it easy to roll back unsuccessful changes with just a couple of clicks.  
- A public interface for knowledge base queries with stricter search and clear responses has been added — simplifying the integration of your documentation with external systems.  
- A new embeddable Storm-CRM booking widget has been added to the site's marketing zone, replacing a third-party service — making demo and meeting scheduling simpler and more stable.

## 🚀 Improvements {#🚀-улучшения}

- The simulation results interface is now more structured and readable, with tabular data displayed more neatly — analyzing modeling outcomes is now more convenient.  
- Automatic layout of BPMN diagram elements is now neater, and precise geometry adjustment tools are more convenient, simplifying the process of making diagrams look presentable.  
- Copying the diagram name is now available in any status and from the header — making it easier to share links and format documents.  
- Text annotations on diagrams now align correctly to the left edge when the font size is changed — diagrams look neater.  
- The role card now displays the planned duration — making it easier to assess workload and plan participant involvement in the process.  
- AI chat operation is now more predictable: knowledge base search has been improved, and the number of "refusals" and inaccurate responses has been reduced — you can rely more on the assistant's suggestions.  
- A unified AI section, an enable toggle, and license tracking have been added to the AI chat — access management for AI features is now more transparent.  
- Knowledge base search handles keyword queries better — the required articles are found more often and more accurately.  
- The public site and marketing pages load significantly faster, especially for unauthenticated users, improving the first-time product experience and SEO.  
- Fonts and analytics loading have been optimized — the interface opens and responds faster without distracting from work.  
- The "team not found" block interface has been improved — messages are now clearer and less intrusive.

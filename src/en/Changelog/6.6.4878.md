## ✨ New Features {#✨-новые-возможности}

- Process import and update capabilities have been expanded: when loading models, the system more carefully updates existing processes, descriptions, and connections, simplifying the maintenance of a single source of truth for processes.
- A new server-side business process scoring service has been added — this serves as the foundation for future analytical features and more accurate assessment of process model quality.
- Object registry import handling has been improved: upon re-import, data is updated, more detailed descriptions can be stored, and objects can be linked to the required entities, reducing manual effort and the risk of discrepancies.
- Direction types have been added to asset edges, allowing for a more precise description of how objects are connected to each other (who is the source and who is the recipient).
- A draft page for discrete event simulation (DES) with access control has been introduced: it is now possible to plan in advance who will be able to run which simulation scenarios.

## 🚀 Improvements {#🚀-улучшения}

- The export interface has been updated: export is now performed asynchronously in a new, more convenient window, making the process clearer and preventing it from blocking work in the system.  
- The interface for importing processes and working with the registry has been improved: it is now easier to navigate fields, descriptions, and relationships, which reduces the likelihood of errors when loading data.  
- The dark theme on the AI platform landing pages has been refined: information is more readable, and the interface looks neater and more consistent.  
- Localization of the "Users" and "Org Structure" sections has been improved: texts and labels are now clearer and more consistent with each other.

## 🔧 Fixes {#🔧-исправления}

- Fixed issues with real-time data updates in the org structure: changes to employees and departments are now reliably displayed without unexpected "rollbacks."  
- Removed duplicates from employee autocomplete tooltips, making the search for a specific person cleaner and more intuitive.  
- Removed edit buttons from the diagram table for users with "view-only" permissions and updated tooltip texts: the interface no longer suggests actions that are unavailable to such users.  
- Improved link rendering in the text editor (CKEditor) and hidden an unnecessary keyboard shortcut hint to avoid distractions while working with the document.

## ✨ New Features {#✨-новые-возможности}

- The process optimization window now highlights and explains detected improvements — making it easier to understand exactly what the system recommends changing and why.  
- On optimization pages, you can adjust the font size to comfortably work with large volumes of text and comments.  
- New filters have been added to the diagram version view — making it easier to find the required process model version among a large number of changes.  
- A button to switch to the extended plan has been added to the AI process creation window — allowing you to immediately see which additional features are available and how to enable them.  
- A "Regulations" tab has been added to the record card in the process registry — regulations are now always at hand next to the process model.  
- A new onboarding and templates have been added to the surveys and feedback section — making it easier to launch initial surveys and select the appropriate question format.  
- A three-phase trial period widget has been added to the product header — it visually shows how much time is left until the end of the trial and helps you not miss the moment to connect a plan.  
- A banner about switching to the BUSINESS plan has been added to the team processes page — allowing you to quickly learn about business plan features and proceed to the upgrade.  
- Micro-onboarding has been added to the "Regulations" tab in the regulations section — new users can faster understand how to work with regulations in the system.  

## 🚀 Improvements {#🚀-улучшения}

- Improved the email user invitation process: the system now correctly handles cases where a user is already part of another team and provides clearer feedback.  
- Restricted shared access to diagrams in several scenarios — this helps better control who can work with process models.  
- Improved tag search functionality when saving a diagram — tags are now matched more accurately, making navigation easier across a large number of models.  
- Updated the new model creation interface: the button has been renamed to “New Model” and opens a convenient modal window — starting modeling is now simpler and more intuitive.  
- Improved interface colors in the dark theme — elements are now more readable and look more polished.  
- Redesigned the “mega-menu” in the site header to prevent columns from misaligning — navigation is now neater and more user-friendly across different screen sizes.  
- Added image support to two-column marketing blocks — promotional materials and training blocks are now more visually appealing.  
- Improved the interface of the BPM CBOK page and related materials (banners, authors, navigation, headings) — it is now easier to find useful BPM content and navigate the material series.  

## 🔧 Fixes {#🔧-исправления}

- Improved the stability of saving previews for regulations — images and covers are now saved and displayed correctly.  
- Fixed issues with loading and displaying comments and approvals — the discussion history and process approval statuses are now shown fully and without errors.  
- Corrected the display of approval history in the regulations registry, including the "Pending" status — status changes are now displayed correctly.  
- Resolved errors when working with diagram versions and their comparison — viewing and switching between versions is now more reliable.  
- Improved error handling during the preloading of styles and other resources — the process designer pages are less prone to unexpected failures.  
- Fixed the functionality of the custom sidebar — menu items are now displayed correctly and do not "break" the interface.  
- Fixed access to export, removal of redundant assistants, and protection against malicious content in the surveys section — export is now more reliable, and user data is safer.  
- Improved the operation of authentication and system logout: removed the "flickering" paywall when loading pages, and corrected account logout and subscription plan information updates.  
- Added more understandable error messages during payment — it is easier for the user to understand what went wrong and what to do next.  
- Fixed rare errors when connecting to the database and processing ADFS tokens — the system is now more stable during login and when working with corporate authentication.

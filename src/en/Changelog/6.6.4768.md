## ✨ New Features {#✨-новые-возможности}

- A new table view mode for the org structure has been introduced: you can quickly search for employees and departments, edit data directly within a row, and see matches highlighted — this simplifies navigation in large organizations.
- A dedicated approvals page for users with "view" permissions has been added: now even viewers can conveniently track approval statuses in one place.
- The BPMN editor now features a modern diagram display mode with a minimap, improved navigation, and the ability to switch between the classic and new views — working with large diagrams has become simpler and more intuitive.
- Keyboard control for the BPMN diagram (WASD and arrow keys) has been implemented: you can navigate the diagram and edit elements with minimal mouse usage, which speeds up work for experienced users.
- "Bridges" have been added at connection intersections in BPMN (the "jumping" line effect): complex diagrams are now easier to read, and connections no longer blend into each other.
- A "Lanes view" mode has been introduced — a separate read-only view of the BPMN diagram by lanes (swimlanes), which is convenient for presentations and process approvals without the risk of accidental changes.
- BPMN elements now feature role-based highlighting and "ghost" overlays for roles and architectural elements: it is now easier to see who is responsible for what and how elements are linked to the corporate architecture.
- Smart email address autocomplete has been added to the sharing form: the system suggests colleagues' addresses, which speeds up access provisioning and reduces the risk of input errors.
- The "Command Processes" page has undergone a visual redesign: the structure is now clearer, and key actions are more prominent, making navigation easier for new users.
- A partner program and partner catalog have been launched: you can find certified consultants and integrators for STORM implementation and development in your company.
- A "Contact Sales" form has been added with automatic request handling: it is now easier to request a commercial proposal, a consultation on pricing, or a license extension.  

## 🚀 Improvements {#🚀-улучшения}

- The visual design of the BPMN editor has been updated: contrast has been improved, palette and event colors have been unified, and the positioning of tooltips and overlays has been refined — diagrams now look neater and are easier to read.
- Text annotations and labels in BPMN now better adapt to element styling (colors, positioning when the font changes), making diagrams more orderly during editing.
- New floating panels and menus have been added (including for the org structure and BCM): key actions are always within reach, while the diagram workspace remains maximally uncluttered.
- Zoom and diagram navigation have been improved: standard keyboard shortcuts are intercepted, the token simulator has been moved to the menu, and large diagrams are easier to scale and view.
- In VIEW mode and for "viewers," unnecessary create and edit buttons, as well as calls to action, are hidden — the interface is cleaner and safer for users without editing permissions.
- Element highlighting in the org structure and improved recalculation of table data make working with large structures more stable and understandable: changes in nodes are correctly reflected in all views.
- Tooltips and onboarding scenarios have been improved: element highlighting, transitions, and banner delays have become more predictable, and tooltips are better timed.
- Colors and icons in the support and chat interface have been updated, and the chat widget is hidden for students: this reduces visual noise and makes support a neater part of the product.
- Autocomplete forms (including for employees) have expanded data sources and improved filtering by email, speeding up the search for specific people.  

## 🔧 Fixes {#🔧-исправления}

- Improved the behavior of copying element styles, undo/redo actions, and the context menu in the diagram editor — typical editing operations have become more predictable and reliable.  
- Fixed rare issues with the positioning of popovers and previews on large diagrams and in guest view, ensuring that information is always displayed next to the relevant element.  
- Resolved errors when duplicating diagrams of all types, including non-XML: copying schemas now works correctly without unexpected redirects.  
- Fixed specific issues with the display of the "Changes" tab and the empty approvals tab, so users always see the current history and statuses.  
- Refined login validation for corporate licenses: redundant email and password validation has been disabled, eliminating false authorization errors.  
- Fixed minor visual defects: disappearing badges, incorrect onboarding frame, checkbox behavior in overlays, etc., to ensure the interface looks and behaves consistently.  
- Resolved issues with long business event names and text on collapsed participants in BPMN, preventing labels from being truncated or misaligned.  
- Fixed rare conflicts and stale data in the browser's local storage (IndexedDB), reducing the risk of unexpected errors when working in multiple tabs.

## ✨ New Features {#✨-новые-возможности}

- Global search (Ctrl+K) now allows finding not only processes and process models but also org structure elements and employees — this speeds up navigation and searching for specific people across the company.
- A "Summary" tab has been added to the simulation report, featuring "process health" metrics and key KPIs — making it easier to quickly assess where the process is performing well and where bottlenecks exist.
- A path panel and route highlighting have been added to the "Diagram" tab in the simulation report — allowing you to visually see which scenarios the process most frequently follows.
- A live resource status (available / unavailable) has been added to the task card — this helps you immediately understand whether a step can be executed right now, without switching to other systems.
- In the process regulation (DOCX), links to related processes in the "Process Links" section are now clickable — making it convenient to navigate to the required process models directly from the document.
- A "multi-select" type has been added for reference fields — you can now select multiple values from a list at once, simplifying work with complex classifiers.
- In the process registry, the card can now automatically pull related data (roles, units of analysis, positions) from the main process model — reducing manual duplication and discrepancies.
- The validation logic for BPMN training assignments (bpmn-connect) has been updated: the system now evaluates the correctness of node placement rather than random matches — making it easier for users to understand how well they have actually mastered the material.
- A dedicated section with registration capability and a prominent announcement badge has been added to the demo days landing page — making it easier to sign up for a product demonstration.
- A dark theme has been added for the payment widget — the payment interface now fits better into dark designs and looks more polished.
- New rewards have been added to the achievements system for paid B2B invoices and long-term use of Storm (including merchandise), while the outdated "course" achievement has been removed — the conditions have become more transparent and relevant.

## 🚀 Improvements {#🚀-улучшения}

- The diagram scale and initial focus in the general BPMN canvas are now automatically adjusted — diagrams are easier to view and edit without manual fitting.  
- Charts in simulation reports (dynamics and economics) are now more intuitive: convenient tooltips on hover have been added, and redrawing when switching runs has been improved — data updates smoothly without "jitter."  
- In BPMN training assignments, the validation and restoration of the final screen after a page reload have been improved — progress is not lost, and the learning process is smoother.  
- The "User Activity" section in the admin panel now correctly scales to the screen — information is readable without horizontal scrolling.  
- The link between the user profile and analytics has been improved: the user identifier is set after the profile is loaded — reports on actions become more accurate.  
- In the wiki, labels for page export and import have been improved, and the styling of attachment cards (icon and "Replace file" text) has been updated — working with documentation has become clearer.  
- Typography for marketing pages and the logo have been updated, and a "Document with Table of Contents" block has been added — long materials on the site are easier to read and look more professional.

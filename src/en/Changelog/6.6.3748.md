## ⚠️ Changes for Enterprise clients {#⚠️-изменения-для-enterprise-клиентов}

Due to the migration from Spring Boot 2 to Spring Boot 3, the following is required to install the new version:

### Change environment variables {#изменить-переменные-окружения}

**1. PATH**

```bash
# Было (Java 11)
/usr/local/openjdk-11/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

# Стало (Java 21)
/opt/java/openjdk/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

**2. JWTSECRET**

The new version requires stricter key validation. Tokens are signed with the **HS512** algorithm, which requires a key **no shorter than 512 bits — a minimum of 64 characters**. With a short key, the application will reject user login with an error `WeakKeyException` in the logs.

Length check:
```bash
echo -n "$JWTSECRET" | wc -c   # должно быть ≥ 64
```

Generating a new key (if the current one is short):
```bash
openssl rand -base64 64 | tr -dc 'a-zA-Z0-9' | head -c64
```

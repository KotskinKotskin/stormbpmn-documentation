## ✨ New Features {#✨-новые-возможности}

- The AI model creation window now includes a button to upgrade to the extended plan — making it easier to understand which additional features are available and how to enable them.  
- A dedicated tab for the regulation has been added to the object card in the registry — all key documents and operational rules are now consolidated in one place.  
- Author pages and improved search functionality have been added to the blog — making it easier to find useful articles and follow publications from specific experts.  
- Subheadings and second-level headings have been added to the blog author page — making specialist information more structured and visually clear.  
- Font size controls have been added to the optimization pages — allowing you to adjust the text scale for your comfort and reduce eye strain.  
- A section with a STORM implementation guide has been added to the website — helping you organize the product launch in your company step by step.  
- The landing page for the STORMCONF26 conference has been launched, featuring a registration form and program description — making it convenient to learn event details and submit your application immediately.  

## 🚀 Improvements {#🚀-улучшения}

- The button for creating a new model has been renamed to "New Model" and now opens a window for selecting the type — it is now clearer what you are creating, making it easier to get started.  
- "Infinite" scrolling has been added to the diagram version list — older versions are loaded as you scroll, eliminating the need for extra pagination clicks.  
- The diagram version filter has been configured to hide auto-saves — the list is now cleaner and more convenient for finding the required pinned version.  
- The display of the approval history in the Registry has been improved: pending approval statuses are now visible — making it easier to track which stage a document is at.  
- Colors and shadows in the interface have been improved in the dark theme — elements look neater and are more readable.  
- The operation of polls and custom responses in the feedback section has been improved — reusing pre-set responses has become more reliable and predictable.  
- The layout and animations on marketing pages (landings, conference) have been refined, especially on mobile devices — pages load faster and are easier to read without horizontal scrolling.  
- SEO settings for specific pages (including the Stormverse leaderboard and blog) have been improved: metadata and structured data have been added — this helps better find STORM materials through search engines.  

## 🔧 Fixes {#🔧-исправления}

- Improved tag search behavior when saving a diagram — tags are now correctly found and applied.  
- Fixed issues with editing custom comments on elements — you can now confidently edit your notes without failures.  
- Clarified the logic for the "as-is / to-be" linkage for related diagrams and when loading into folders — links between process models are displayed correctly.  
- Eliminated rare errors when comparing and importing diagrams, as well as when working with proxy objects — model import and comparison have become more stable.  
- Improved error handling when loading the interface after a system version update: in case of a failure, the page automatically reloads and continues to work.  
- Fixed the behavior of the side panel and individual interface elements (checkboxes, canvas focus) — interaction with diagrams has become more predictable and convenient.  
- Updated the platform's security mechanisms and access denial handling — overall system security has been improved without changing familiar workflows.  
- Fixed specific issues with access to surveys on the Team plan — users of the team plan receive the correct set of feedback features.  
- Eliminated errors in the operation of team admin pages and search for them — team management and searching for a team by name work correctly.  
- Fixed specific issues with saving and displaying procedure previews and with metrics accounting — data on procedures and analytics is displayed correctly.

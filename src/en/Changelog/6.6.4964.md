## ✨ New Features {#✨-новые-возможности}

- BPMN diagram analysis and a process quality assessment service have been introduced: you can now obtain quantitative quality metrics for diagrams and identify problem areas in process models more quickly.
- Tools for simulation modeling (Simulation) and simulation status display have been added: this simplifies working with process execution scenarios and monitoring their state.
- A slash command popup list (triggered by the “/” symbol) has been added to the wiki editor: this speeds up inserting standard blocks and structuring documentation.
- Support for video in large promo blocks has been added to the corporate website, and the dark theme for the AI platform has been improved, making the product presentation more visual and modern.
- Support for the direction of connections between objects has been added to the asset registry: this helps better understand how infrastructure elements influence each other.
- A “classic” mode has been added to shared diagram links, allowing diagrams to be opened in the familiar interface without additional actions.

## 🚀 Improvements {#🚀-улучшения}

- Improved process import and registry record updates during re-import: reduced risk of duplicates and easier maintenance of process model currency.
- Enhanced the process registry: smoother tree loading, preservation of selected filters, correct operation in dark theme, and convenient dropdown lists for selecting the parent process.
- Updated the diagram export interface: export runs asynchronously, and the new screen makes the process clearer and more intuitive.
- Improved the diagram version list interface (custom scrollbar) and the diagrams table (edit buttons hidden in "view only" mode), making version management and access rights more transparent.
- Restored task count indicators for approval in the personal menu; authors and editors can now resubmit approval requests, accelerating the process approval cycle.
- Improved selection of assignees and roles: only roles available to the process model author can be selected, reducing assignment errors.
- Improved behavior in the org structure during changes (fewer "hangs" and unnecessary reloads), and employee autocomplete no longer shows duplicates, speeding up the search for specific people.
- Enhanced hints, link formatting, syntax highlighting, and hotkey functionality in the wiki editor and text fields, making text editing more comfortable.
- Added a dark theme to the process description editor and improved flow element parsing, facilitating work during long modeling sessions and reading large diagrams.
- Improved the interface for anonymous and view-only users: removed inaccessible blocks and "call to action" messages to avoid misleading users without editing rights.
- Improved avatar and user photo display in the system header, making profiles neater and more recognizable.

## 🔧 Fixes {#🔧-исправления}

- Improved the stability of process imports and the rollback of changes when an import is canceled, reducing the risk of "stuck" states and partially loaded data.
- Fixed issues with exporting diagrams to SVG/PNG (including in Firefox) and duplicate pages in PDF, and improved notifications during export.
- Resolved errors when displaying the registry tree, making repeated server requests, and refreshing the page, ensuring the registry operates predictably without "jumps."
- Fixed specific issues with BPMN element auto-numbering to ensure numbers are correctly added to names without corrupting existing names.
- Removed visual artifacts in the dark theme, corrected the width of dropdown panels, and fixed overlay rendering on diagrams to improve diagram readability.
- Removed the "Unavailable" block in the sidebar for anonymous users and adjusted texts in the diagram viewer for "read-only" mode to make the interface clearer.
- Fixed specific issues with multi-line data in the payment form, file link generation, and CloudPayments display, reducing errors during payment and attachment handling.
- Resolved minor localization errors (including German), such as incorrect characters and hardcoded strings, making the interface more consistent.
- Fixed known limitations and visual inaccuracies in the wiki editor, as well as issues with syntax highlighting and tooltip behavior.

## ✨ New Features {#✨-новые-возможности}

- **Access request for a diagram.** Now, if you do not have permissions to view or edit a diagram, you can send an access request to the owner directly from the interface, without the need for correspondence in third-party channels.
- **Support for reusable processes.** It is now possible to use the same process in different diagrams as a "building block," which simplifies the maintenance of standard scenarios and reduces the number of duplicate models.
- **Viewing registries without editing permissions.** Separate settings for viewing the registry have been added: you can flexibly manage who sees the data and in what format, without granting unnecessary permissions.
- **"Changes" tab in the registry card.** A separate tab with change history has been added to the registry card, which helps track who made edits and when.
- **Search by INN and convenient work with "Payment by invoice."** The payment by invoice section now includes search by INN and server-side pagination, which speeds up work with a large number of companies.
- **Display of the application version in the profile.** The current version of STORM BPMN is now visible in the profile menu, which simplifies communication with support and colleagues.
- **Configuration of viewing modes for regulations and registries.** The capabilities for configuring viewing modes for regulations and related materials have been expanded so that users see only the content they need in a convenient format.
- **BPMN course section in Content Hub.** A separate section with a BPMN course has been added to the Content Hub, which helps to master the notation faster and improve the quality of models.
- **Tracking of business events.** The system has started collecting more data on key user actions (for example, first login), which will allow for more precise configuration of onboarding and analytics in the future.
- **Improvements to the suggestions form in the roadmap.** The product development suggestions form now includes sorting by date and motivational text, making participation in the development of STORM BPMN more visual and understandable.

## 🚀 Improvements {#🚀-улучшения}

- **Smoother performance with large org structures.** Rendering and element layout calculations for large org structure diagrams have been optimized, resulting in noticeably faster opening and navigation.
- **Improved autosave stability in Plant and BCM editors.** Autosave error handling has become more reliable, reducing the risk of losing unsaved changes.
- **Easier management of team guests.** Not only administrators, but also other users with the appropriate permissions can now view the list of team guests, simplifying collaboration.
- **Correct minimum license boundary.** The minimum number of licenses now automatically accounts for the number of editors in the team, helping to avoid situations where there are insufficient licenses for current users.
- **Clearer license handling when changing plans.** User data is correctly updated after a license change, reducing confusion regarding access and capabilities.
- **More intuitive and tidy overlays for regulations and external links.** The sizes and behavior of external link icons and regulation overlays have been adjusted so they do not obstruct viewing and appear neater.
- **Improved contact form for the sales department.** The "Contact Sales" form now includes validation for the "Company" and "Position" fields, helping to process inquiries faster and reduce the number of incomplete requests.
- **Correct display of the "On your server" plan.** The "On your server" badge is now always associated with the "Organization" plan and displays predictably.
- **Improved handling of payment purpose via bank webhook.** The system more reliably recognizes the payment purpose, reducing the need for manual checks and clarifications.  

## 🔧 Fixes {#🔧-исправления}

- **Improved BPMN diagram handling.** Fixed cursor behavior and element selection when dragging diagrams: text is no longer accidentally selected, and elements display correctly in dark theme (icons and markers are clearly visible).  
- **Stable copy and paste in BPMN.** Eliminated rare errors when pasting elements, which could cause some diagrams to fail to open or behave unpredictably.  
- **Reliable saving of SVG schemas.** Correct encoding is now used when sending SVG schemas to the server, preventing file corruption.  
- **Improved registry behavior when adding parameters and metrics.** When adding new fields, tabs and selected sections are no longer reset, saving time during configuration.  
- **Simplified team invitations.** Removed an unnecessary check (captcha) from the email invitation process, reducing failures when sending invitations.  
- **Correct handling of anonymous access and guests.** Fixed rare errors when toggling anonymous access and managing team guests, ensuring access settings are applied predictably.  
- **Cleaner BPMN editor interface.** Removed an unnecessary third-party library label at the bottom of the diagram to avoid distractions.

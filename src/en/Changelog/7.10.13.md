## ✨ New Features {#✨-новые-возможности}

- A "reader" mode has been added to the editor interface: you can view process models and org structure without the risk of accidentally making changes, while editors continue to work in normal mode.
- The personal account shell now includes an AI assistant and a list of conversations: you can quickly return to previous dialogues and use the assistant directly from the sidebar.
- A "Hypotheses" tab has been added to the simulation report: you can now record and discuss the assumptions on which the process model is based, right next to the calculation results.
- In business process simulation, you can now set gateway branch probabilities with precision to hundredths of a percent — this improves calculation accuracy for complex scenarios.
- The resource calendar now features "breaks" and waiting windows: the system displays when a resource is busy, waiting, or unavailable, and why, simplifying bottleneck analysis.
- A dedicated hub has been added to the corporate architecture registry: you can structure approaches, schools, artifacts, and concepts in a single space.
- Excel import and export for corporate architecture elements has been added: it is now easier to transfer data from other systems and keep it up to date.
- You can now attach files to comments on objects — a convenient way to share documents, screenshots, and additional materials directly within the discussion.
- The shell panel now includes a built-in Wiki and a "reader's cabinet" — users without editing rights get a convenient interface for reading documentation and process models.
- In profile settings, you can set the width and visibility of the sidebar separately for each section — each user can customize their workspace.
- Sorting by columns in the user table has been added to the admin panel, simplifying the search for specific accounts and working with large lists.
- In the team, users with view permissions can now edit the knowledge base within their group permissions without requesting separate access.
- A "What's New" feed has been added to the personal account: important STORM BPMN updates are now visible directly in the interface, without navigating to the documentation.
- Onboarding now includes automatic selection of a tutorial tour based on wizard answers and the user's role in the team — new users find relevant scenarios faster.
- A hint about the ability to connect a custom external agent has been added to the chat, with a quick link to the relevant settings.  

## 🚀 Improvements {#🚀-улучшения}

- In the BPMN process model registry, binding management has been improved: it is now easier to unbind models and view the active model and key metrics directly in the tables.
- In the approvals interface, team administrators have more convenient management of approval processes and history export.
- In simulation reports, methods for analyzing result stability and explaining non-stationarity causes have been improved — conclusions regarding models are now more reliable and clearer.
- In the reader mode, permissions for actions on process models, folders, architecture, roles, and settings have been clarified to ensure the interface always reflects the user's actual capabilities.
- In the new shell, navigation has been simplified: the logo leads to the home page, the "Home" button and headings are aligned, settings are consolidated into a single item, and model creation is available directly from the list header.
- Loading skeletons have replaced spinners in many parts of the interface — pages are perceived as faster and it is clearer what is currently loading.
- In the user table and other lists, search and value selection in dropdown lists have been improved, which speeds up work with large reference data.
- In the password change form, feedback has been improved: in case of a server error, entered data is not lost, and password requirements have become more transparent and consistent.
- In the "What's New" feed and other sections of the reader interface, access rights have been clarified: users without editing permissions see only what is actually available to them.  

## 🔧 Fixes {#🔧-исправления}

- Fixed interface behavior when leaving an unavailable process model page — the personal account header no longer disappears.  
- Improved simulation performance: eliminated rare hangs with very long scenarios and complex branching.  
- When converting diagram groups, the diagram type is now preserved, preventing confusion in process models.  
- Fixed the display of the editor palette in PDF and embedded views — only the diagram itself remains in the final output.  
- In the “Subscriptions and Invoices” section, refund and error statuses are now displayed correctly and no longer fall into the “Unknown status” category.  
- Improved hints and error messages in the password change form and email confirmation screen to make it easier for users to complete the action.  
- In the approvals interface, process duration is now calculated without an extra minute, making metrics more accurate.  
- In the surveys section, the system now explicitly indicates the lack of permissions to create a new survey, instead of an obscure denial.  
- Fixed minor issues with the documentation site’s mega menu at intermediate screen resolutions — the menu opens stably and no longer breaks the layout.

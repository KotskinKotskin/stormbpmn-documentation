## ✨ New Features {#✨-новые-возможности}

- Process simulation details are now available: you can open a dedicated simulation page with a side panel for goals and thresholds to visually configure the metrics that define a result as successful or problematic.
- The diagram editor now supports drilldown into details: you can navigate from the overall schema to more detailed subprocesses directly on the diagram without losing context.
- STORM Wiki (text editor) now includes a "File Attachment" block with a progress indicator and upload cancellation capability, as well as support for various file drag-and-drop methods. This simplifies collecting documents and artifacts for a process in one place.
- The user profile now includes an interface for managing MCP keys: you can independently add, update, and disable access keys without administrator involvement.
- The process registry now features a unified level badge (on the map, in the tree, and on the process card) so you can immediately see the importance or maturity level of a process across all views.
- The BPM CBOK section has been updated with a large-card layout (bento-layout), making navigation through BPM knowledge and standards more visual and convenient to read.

## 🚀 Improvements {#🚀-улучшения}

- The BPMN diagram editor now features improved grid alignment and snap-to-grid behavior, helping you assemble neat and readable diagrams faster.
- Persona management and process lifecycle controls have been redesigned, making it easier to see who is responsible for what and where the process currently stands.
- The automatic BPMN diagram layout engine has been improved: the main process “line” is now aligned more evenly, arrow crossings are reduced, and loops are detected and displayed more accurately.
- The BPMN editor interface has been updated: unnecessary hotkeys (WASD) have been removed, arrow controls have been improved, duration display and element hover highlighting have been redesigned, making the workflow more predictable and pleasant.
- Process search now includes a quick filter reset option, allowing you to easily return to the full list without manually clearing fields.
- In the organization’s employee section, the table’s appearance and scrolling behavior have been improved, and the notification badge positioning in the application header has been refined to ensure important indicators are always visible.
- In shared layouts and team spaces, the team’s primary color and unified logo are now applied correctly, so the brand style does not “reset” when navigating between pages.

## 🔧 Fixes {#🔧-исправления}

- Improved the operation of model import and validation: issue messages are now more reliable, and the checks themselves are more stable.
- Fixed inaccuracies in threshold determination in process simulations and goal settings to ensure calculation results better match your expectations.
- Adjusted task sizes in the BPMN editor when adding via the context menu, ensuring elements remain neat even when the width is changed.
- The diagram name tooltip now appears only when hovering over the name, rather than the entire row, reducing visual noise.
- Fixed a number of minor glitches and inaccuracies in search, settings, and other sections, making the interface behave more consistently and predictably.

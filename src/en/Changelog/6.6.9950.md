## ✨ New features {#✨-новые-возможности}

- The process model list now includes a "Visibility" column and a filter for it — making it easier to manage which models are available to the team and which remain internal drafts.  
- You can now mention participants directly in the text of comments to quickly involve the right colleagues in discussing a specific issue.  
- Wiki discussions can now be attached not only to an entire block but also to a specific text fragment — this simplifies targeted edits and wording alignment.  
- The events page now features a first screen with cards and an announcements block — making it easier to keep track of upcoming activities around STORM BPMN.  
- During loading, a process animation is displayed instead of a blinking logo, more clearly indicating that the system is working and preparing data.

## 🚀 Improvements {#🚀-улучшения}

- In team settings, the generated API key is now displayed immediately without a page reload, speeding up integration setup.  
- Simulation reports have improved table and chart handling: data no longer overlaps, allowing for smooth viewing and scrolling.  
- The wiki interface is now visually cleaner: fonts in the top panel are aligned, the status line during editing is improved, and the display of recent page cards has been enhanced.  
- In the process editor menu bar, elements no longer overlap each other, and the "Save" button is always clickable.  
- Event covers on the marketing activities page now display clearly even when there is only one upcoming event.

## 🔧 Fixes {#🔧-исправления}

- The handover section now handles incomplete simulations and access rights more effectively, ensuring that imports and reports for surveys and diagrams are processed correctly without data loss.  
- Diagram exports and previews, along with their associated tables, are now always consistent, so users see a complete and up-to-date set of materials.

## ✨ New Features {#✨-новые-возможности}

- AI hint management has been added to the settings: administrators can now configure which hints are displayed to users and how exactly to assist them in working with processes.
- The ability to transfer the org structure between registries has been introduced: you can now carefully transfer and align the structure of departments and roles without manual recreation.
- Org structure import (v1.0) has been added: you can upload the organization structure from a file, and the system will automatically adjust the scale and display for immediate convenience.
- A new header and an "expand/collapse all" button have been added to the registry tree: managing large trees of records and quickly finding the required section has become easier.
- A new icon for DES optimizations and a separate guide on optimizations have been added to the modeler: it is now easier for users to distinguish simulation modeling scenarios and find suitable recommendations for process improvement.
- New sections ("problem indicators", "real-life case"), related optimizations, "Optimizations" and "Glossary" tabs, and extended cards have been added to the reference materials and optimizations website: this helps to quickly understand how to apply an optimization to your process.  

## 🚀 Improvements {#🚀-улучшения}

- The process save window opens faster, and the "Save" button is disabled if the name contains an error — this saves time and reduces the risk of accidental invalid saves.  
- The registry tree interface has been improved: it is collapsed by default (if no saved settings exist), levels are displayed more neatly, and filters work more predictably.  
- Labels and visual elements in the interface have been refined (important labels are highlighted, icons display correctly, and tabs have a bottom border) — navigation is now clearer and visually cleaner.  
- The glossary and optimization list have been redesigned: two-column format, a "Getting Started" block, full-width search in each tab, and displaying only relevant terms for the selected optimization make working with the documentation more convenient.  
- The structure of optimization pages has been improved for search and accessibility: FAQ and HowTo schemas have been added, headings have been optimized, and misleading "free" mentions have been removed.  
- Call-to-action banners and transition tracking have been improved in the blog and reference materials, helping to better understand which materials are most helpful to users.  

## 🔧 Fixes {#🔧-исправления}

- Improved diagram sharing functionality: unauthorized users no longer receive excessive permissions when viewing shared diagrams.  
- Fixed errors during category-based import and export (including correct file naming during export), as well as issues with data generation when uploading files.  
- Resolved issues with administrator creation in SaaS mode and the display of payment type and recurring payments, reducing failures during payment and subscription management.  
- Improved the "Back to Top" button and article scrolling: abrupt page "jumps" during reading are eliminated, and the button is no longer obscured by the chat.  
- Corrected specific visual and textual inaccuracies (icons, styles, Russian category names, hiding internal optimization codes) to ensure the interface appears clean and does not confuse users.

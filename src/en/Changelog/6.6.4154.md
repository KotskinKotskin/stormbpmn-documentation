## ⚠️ Changes for Enterprise clients {#⚠️-изменения-для-enterprise-клиентов}

The internal client for working with the file storage has been replaced from the MinioClient SDK to the AWS SDK v2 S3Client.

The update expects full backward compatibility — if your environment variables `MINIO_ENDPOINT`, `MINIO_ACCESSKEY`, `MINIO_SECRETKEY`, and `MINIO_DEFAULTBUCKET` are configured, no additional actions are required. The new client automatically picks up the existing configuration.

Support for vHosted addressing and the ability to work with a single custom bucket has also been added. Details are in the [documentation](../install/production/components.md#настроика-переменных-окружения).

::: tip Need help?
If you notice issues with file uploading or display after the update — contact support.

```bash
# macOS
brew install cosign

curl -sSL https://github.com/sigstore/cosign/releases/latest/download/cosign-linux-amd64 -o /usr/local/bin/cosign
chmod +x /usr/local/bin/cosign
```

```bash
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  cr.selcloud.ru/stormbpmn-enterprise/stormbpmn_fullstack_enterprise:6.6.4154
```

## ✨ New features {#✨-новые-возможности}

- Simulations now include a "Resources" section and color-coded roles: you can configure resources and roles directly in the settings, view their colors in the report, and better understand team workload.

- A "My" tab has been added to the simulation list, and author information is now displayed on cards: it is easier to find your own runs and see who is responsible for what.
- You can reset a calculated simulation to draft: settings can be easily adjusted and the simulation restarted without creating copies.
- Monitoring of active runs has been added to the simulation list: you can see which simulations are currently being calculated and do not need to guess if something has hung.
- The simulation element panel now features field groups and highlighting when clicking a badge: required parameters are found faster, and navigation through complex settings is simpler.
- "Back/Forward" navigation between elements has been added to the simulation sidebar: you can sequentially traverse elements without extra clicks on the diagram.
- The simulation report has an expanded "Scenarios" summary and top paths: key scenarios and main process routes are visible at a glance, without deep diving into details.
- An anonymous link to a public simulation report with AI analysis has been added: you can safely share results with external participants and receive automated analysis.
- A trash bin has been added to the knowledge base (wiki): deleted pages can be viewed and restored, eliminating the fear of losing important materials.
- Anonymous links and comment threads have been added for wiki pages: it is convenient to collect feedback from external participants and discuss materials in one place.
- Contextual help for simulations and reports has been added: (i) icons open ready-made Help Center articles directly in the interface, without distracting from work.
- The main page now features a "Registry Processes" block and charts: key processes and dynamics are visible immediately after logging into the system.
- An "Events" item with live preview has been added to the mega menu: you can quickly orient yourself in events and navigate to the required activities.
- Onboarding now includes a question about the name, which is saved to the profile: new users receive a more personalized interface.
- A convenient interface for groups has been added for managing access to folders: you can restrict access and immediately see where restrictions are applied.
- Employee cards in the org structure have been expanded: they display roles in processes, positions, and colleagues, and the full name links to a detailed card.

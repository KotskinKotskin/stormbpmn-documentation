::: details Image signature verification (Cosign)
All Docker images are cryptographically signed using [Sigstore Cosign](https://docs.sigstore.dev/). To verify the authenticity of the image:

**1. Install Cosign:**
```bash
# macOS
brew install cosign

# Linux
curl -sSL https://github.com/sigstore/cosign/releases/latest/download/cosign-linux-amd64 -o /usr/local/bin/cosign
chmod +x /usr/local/bin/cosign
```

**2. Verify the signature:**
```bash
cosign verify \
  --certificate-identity-regexp="https://github.com/KotskinKotskin/stormfullstack/*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  registry.stormbpmn.com/stormbpmn-enterprise/stormbpmn_fullstack_enterprise:9.26.18
```

Successful verification guarantees that the image was built in the official CI/CD and has not been tampered with.
:::

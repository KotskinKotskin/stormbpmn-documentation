# Temporary Work in the System {#временная-работа-в-системе}

Guide for connecting temporary users (interns, contractors) to perform specific tasks.

::: tip Application
Suitable for situations where you need to:

-   Provide temporary access to an intern or contractor
-   Obtain the work result and reclaim authorship
-   Free up a license after task completion

:::

## Working with different license types {#работа-с-разными-типами-лицензии}

### Concurrent Licenses {#конкурентные-лицензии}

For **concurrent licenses**, the procedure is maximally simplified:

::: tip Simple Solution
No additional operations are required - simply create an account and grant access.

A temporary user will occupy a slot only during active work.
:::

### Named Licenses {#именные-лицензии}

A special seat management procedure is required for **named licenses**.

**Step-by-step algorithm:**

| Step | Action                       | Description                                                           |
| --- | ------------------------------ | ------------------------------------------------------------------ |
| 1   | **License Release**      | Temporarily disable an inactive user to free up a seat |
| 2   | **Intern Registration**        | Create a temporary user account                    |
| 3   | **Account Activation**   | Enable the intern's account in the administrative interface      |
| 4   | **Work Execution**          | The temporary user works within the assigned team       |
| 5   | **Results Handover**       | The intern completes the work and hands over the results                      |
| 6   | **Authorship Transfer**         | The team administrator takes over the authorship of the diagrams          |
| 7   | **Account Deactivation** | Disable the intern's account                                   |
| 8   | **Access Restoration**     | Return the license to the permanent employee                            |

::: warning Important points

-   **Plan ahead** - ensure you have inactive users available for temporary deactivation
-   **Monitor deadlines** - do not forget to deactivate temporary accounts
-   **Preserve results** - always transfer diagram authorship before deactivation

:::

## ✨ Новые возможности

- Появился режим просмотра зрелости процессной архитектуры: система рассчитывает интегральный балл по вашим моделям и показывает, насколько вы близки к уровню лучших команд. Это помогает понять текущее состояние, увидеть зону роста и аргументировать изменения перед руководством.  
- На главной странице добавлен компактный блок зрелости: видно общий балл, шкалу с ориентиром «лучшие 10%» и краткий следующий шаг. Это даёт быстрый ответ «как у нас дела» без погружения в детали.  
- В Призме можно загружать файлы прямо с главной страницы и запускать разбор из единой точки входа. Это упрощает старт работы с моделями и сокращает количество переходов по интерфейсу.  
- В Призме появился режим выбора среди похожих вариантов с отдельным фильтром «Требуют выбора». Это ускоряет ревью, когда нужно принять решение по нескольким конкурирующим версиям модели.  
- В редакторе карт процессов добавлены операции с откатом и стеком действий (Ctrl+Z). Теперь можно смело экспериментировать со схемой, зная, что любое действие легко отменить.  
- В таблицах (data-grid) появилось выделение диапазона: через Shift+клик, Shift+стрелки, протяжку мышью и копирование Ctrl+C. Это ускоряет работу с большими списками задач и атрибутов процессов, особенно при переносе данных в отчёты.  
- В разделе метрик добавлено окно выбора периодов, колонка «Период» и журнал изменений по периодам. Это позволяет точнее анализировать динамику показателей процессов и отслеживать, кто и когда менял значения.  
- В ИИ-чате появилась наглядная карточка «упора в лимит» под ответом: система объясняет, почему модель не продолжает работу, и показывает, что именно было ограничено. Это снижает неопределённость для пользователей и помогает планировать дальнейшие шаги.

## 🚀 Улучшения

- Экспорт и импорт реестров теперь сопровождаются более понятными сообщениями об ошибках хранилища файлов, с подсказками для администратора. Это упрощает диагностику проблем при обмене данными между контурами.  
- Просмотр моделей на ревью дополнен сводкой, раскадровкой шагов и превью схемы. Экспертам проще оценивать модель целиком и видеть логику процесса без лишних кликов.  
- Работа с комментариями стала удобнее: реакции отображаются прямо под текстом, время сообщения видно рядом с именем автора, подсказка в поле ввода показывается только в пустом поле, а сочетание Ctrl+Enter явно подсвечено в интерфейсе. Это ускоряет обсуждения и снижает количество ошибок при отправке сообщений.  
- Метка «Новые» в тредах комментариев теперь гаснет только у реально открытого обсуждения, а клики по меткам блоков ведут к нужному треду. Это помогает не терять непрочитанные обсуждения в больших моделях.  
- История согласований остаётся видимой и непрерывной даже при обновлении статуса или отзыве решения. Пользователи всегда видят полный контекст, кто и что уже согласовал.  
- Карточка процесса и действия с моделями корректно учитывают активную команду и членство пользователя. Это снижает риск путаницы при работе в нескольких командах.  
- Загрузка и просмотр больших организационных структур стали заметно быстрее и стабильнее. Навигация по сложным оргструктурам теперь не тормозит и не отвлекает от анализа.  
- Встроенная справка и база знаний получили обновлённую верстку и более аккуратные подписи таблиц и заголовков. Статьи выглядят как единое информационное пространство и удобнее читаются на разных размерах экрана.  
- Меню аватара в шапке больше не «обрезается» по правому краю окна. Все действия с профилем и командами всегда доступны.  

## 🔧 Исправления

- Улучшена работа скачивания файлов: система корректно обрабатывает типы файлов и готова к более строгим настройкам безопасности в браузере.  
- В ИИ-функциях устранены редкие обрывы сессий и повторные уведомления об окончании ответа, чтобы диалоги проходили ровнее.  
- Подсказки и статусы по лимитам использования моделей стали точнее: отказ по лимиту не теряется при нестабильном соединении, а после освобождения места система корректно возобновляет работу.  
- В ИИ-подсказках по следующему элементу процесса предотвращены циклические рекомендации. Это делает предложения по развитию схемы более осмысленными.  
- В карточке процесса и при рендеринге схем устранены ошибки доступа и редкие проблемы с ограничениями на количество построений.  
- В разделе метрик исправлены пограничные случаи при изменении и удалении значений, а также отображение пустых метрик. Журнал изменений теперь не содержит служебных копий и отражает только реальные действия пользователей.  
- В командной работе устранены проблемы с приглашениями и повторными приглашениями участников, а также с открытием моделей для уже приглашённых пользователей. Это снижает количество сбоев при онбординге новых коллег.  
- В интерфейсе комментариев исправлены вторичные упоминания через «@» и поведение поля ввода в сложных сценариях. Уведомления и переходы по обсуждениям стали предсказуемее.

::: details Проверка подписи образа (Cosign)
Все Docker образы криптографически подписаны с помощью [Sigstore Cosign](https://docs.sigstore.dev/). Для проверки подлинности образа:

**1. Установите Cosign:**
```bash
# macOS
brew install cosign

# Linux
curl -sSL https://github.com/sigstore/cosign/releases/latest/download/cosign-linux-amd64 -o /usr/local/bin/cosign
chmod +x /usr/local/bin/cosign
```

**2. Проверьте подпись:**
```bash
cosign verify \
  --certificate-identity-regexp="https://github.com/KotskinKotskin/stormfullstack/*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  registry.stormbpmn.com/stormbpmn-enterprise/stormbpmn_fullstack_enterprise:9.29.9
```

Успешная проверка гарантирует, что образ собран в официальном CI/CD и не был изменён.
:::

# Версия 6.6.3697 от 27.01.2026

## ✨ Новые возможности

- Добавлено управление AI-подсказками в настройках: администраторы могут сами настраивать, какие подсказки показывать пользователям и как именно им помогать при работе с процессами.  
- Появилась возможность переноса оргструктуры между реестрами: теперь можно аккуратно переносить и выравнивать структуру подразделений и ролей без ручного пересоздания.  
- Добавлен импорт оргструктуры (v1.0): вы можете загрузить структуру организации из файла, а система автоматически подстроит масштаб и отображение, чтобы сразу было удобно работать.  
- В дереве реестра появился новый заголовок и кнопка «раскрыть / свернуть всё»: стало проще управлять большими деревьями записей и быстро находить нужный раздел.  
- В моделере добавлен новый значок для DES-оптимизаций и отдельный гид по оптимизациям: пользователям проще отличать сценарии имитационного моделирования и находить подходящие рекомендации по улучшению процессов.  
- На сайте справочных материалов и оптимизаций появились новые разделы («признаки проблемы», «реальная история»), связанные оптимизации, вкладки «Оптимизации» и «Глоссарий», а также расширенные карточки — это помогает быстрее понять, как применить оптимизацию к своему процессу.  

## 🚀 Улучшения

- Окно сохранения процесса открывается быстрее, а кнопка «Сохранить» блокируется, если в названии есть ошибка — это экономит время и снижает риск случайных некорректных сохранений.  
- Улучшен интерфейс дерева реестра: по умолчанию оно свернуто (если нет сохранённых настроек), уровни отображаются аккуратнее, фильтры работают более предсказуемо.  
- Уточнены подписи и визуальные элементы в интерфейсе (важные подписи выделены, иконки отображаются корректно, вкладки получили нижнюю границу) — навигация стала понятнее и визуально чище.  
- Глоссарий и список оптимизаций переработаны: двухколоночный формат, блок «С чего начать», полноширинный поиск в каждой вкладке и показ только релевантных терминов для выбранной оптимизации делают работу со справкой удобнее.  
- Улучшена структура страниц оптимизаций для поиска и доступности: добавлены FAQ и HowTo-схемы, оптимизированы заголовки, убраны упоминания «бесплатно» там, где это могло вводить в заблуждение.  
- В блоге и справочных материалах улучшены баннеры с призывом к действию и отслеживание переходов, что помогает точнее понимать, какие материалы лучше помогают пользователям.  

## 🔧 Исправления

- Улучшена работа общего доступа к диаграммам: неавторизованные пользователи больше не получают лишних прав при просмотре расшаренных диаграмм.  
- Исправлены ошибки при импорте и экспорте по категориям (включая корректное имя файла при выгрузке), а также проблемы с формированием данных при загрузке файлов.  
- Устранены проблемы с созданием администраторов в SaaS-режиме и с отображением типа платежа и рекуррентных платежей, что снижает количество сбоев при оплате и управлении подпиской.  
- Улучшена работа кнопки «Наверх» и прокрутки статей: исчезают резкие «скачки» страницы при чтении, а кнопка не перекрывается чатом.  
- Исправлены отдельные визуальные и текстовые неточности (иконки, стили, русские названия категорий, скрытие внутренних кодов оптимизаций), чтобы интерфейс выглядел аккуратно и не путал пользователей.

::: details Проверка подписи образа (Cosign)
Все Docker образы криптографически подписаны с помощью [Sigstore Cosign](https://docs.sigstore.dev/). Для проверки подлинности образа:

**1. Установите Cosign:**
```bash
# macOS
brew install cosign

# Linux
curl -sSL https://github.com/sigstore/cosign/releases/latest/download/cosign-linux-amd64 -o /usr/local/bin/cosign
chmod +x /usr/local/bin/cosign
```

**2. Проверьте подпись:**
```bash
cosign verify \
  --certificate-identity-regexp="https://github.com/KotskinKotskin/stormfullstack/*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  registry.stormbpmn.com/stormbpmn-enterprise/stormbpmn_fullstack_enterprise:6.6.3697
```

Успешная проверка гарантирует, что образ собран в официальном CI/CD и не был изменён.
:::

## ✨ Новые возможности

- В окне создания модели с помощью ИИ появилась кнопка перехода на расширенный тариф — теперь проще понять, какие дополнительные возможности доступны и как их подключить.  
- На карточке объекта в Реестре появился отдельный таб с регламентом — все ключевые документы и правила работы теперь собраны в одном месте.  
- В блоге появились страницы авторов и улучшен поиск по материалам — легче находить полезные статьи и следить за публикациями конкретных экспертов.  
- На странице автора блога добавлены подзаголовок и заголовок второго уровня — информация о специалисте стала более структурированной и наглядной.  
- На страницах оптимизации добавлено управление размером шрифта — можно настроить удобный для себя масштаб текста и снизить нагрузку на глаза.  
- На сайте появился раздел с гайдом по внедрению STORM — помогает шаг за шагом организовать запуск продукта в компании.  
- Запущена лендинг-страница конференции STORMCONF26 с формой регистрации и описанием программы — удобно узнать детали мероприятия и сразу оставить заявку.  

## 🚀 Улучшения

- Кнопка создания новой модели переименована в «Новая модель» и теперь открывает окно с выбором типа — стало понятнее, что именно вы создаёте, и проще начать работу.  
- В списке версий диаграммы добавлена «бесконечная» прокрутка — старые версии подгружаются по мере пролистывания, без лишних кликов по пагинации.  
- Фильтр версий диаграмм настроен так, чтобы не показывать автосохранения — список стал чище и удобнее для поиска нужной зафиксированной версии.  
- В Реестре улучшено отображение истории согласования: теперь видны и ожидающие согласования статусы — проще контролировать, на каком этапе находится документ.  
- В тёмной теме улучшены цвета и тени в интерфейсе — элементы выглядят аккуратнее и лучше читаются.  
- Улучшена работа опросов и собственных ответов в разделе обратной связи — повторное использование заготовленных ответов стало надёжнее и предсказуемее.  
- На маркетинговых страницах (лендинги, конференция) доработана вёрстка и анимации, особенно на мобильных устройствах — страницы быстрее загружаются и удобнее читаются без горизонтальной прокрутки.  
- Улучшены SEO-настройки отдельных страниц (включая лидерборд Stormverse и блог): добавлены метаданные и структурированные данные — это помогает лучше находить материалы STORM через поисковые системы.

- Уточнена логика работы связки «как есть / как должно быть» для связанных диаграмм и при загрузке в папки — связи между моделями отображаются корректно.

- Обновлены механизмы безопасности платформы и обработка отказов в доступе — повышена общая защищённость системы без изменения привычных сценариев работы.

::: details Проверка подписи образа (Cosign)
Все Docker образы криптографически подписаны с помощью [Sigstore Cosign](https://docs.sigstore.dev/). Для проверки подлинности образа:

**1. Установите Cosign:**
```bash
# macOS
brew install cosign

# Linux
curl -sSL https://github.com/sigstore/cosign/releases/latest/download/cosign-linux-amd64 -o /usr/local/bin/cosign
chmod +x /usr/local/bin/cosign
```

**2. Проверьте подпись:**
```bash
cosign verify \
  --certificate-identity-regexp="https://github.com/KotskinKotskin/stormfullstack/*" \
  --certificate-oidc-issuer="https://token.actions.githubusercontent.com" \
  registry.stormbpmn.com/stormbpmn-enterprise/stormbpmn_fullstack_enterprise:6.6.3983
```

Успешная проверка гарантирует, что образ собран в официальном CI/CD и не был изменён.
:::

1. Сделайте отдельную ветку с документацией.
2. Внесите изменения в нужные файлы.
3. Сделайте коммит.
4. Сделайте пул-реквест в ветку main.
5. ...
6. Вы великолепны, спасибо!

## Переводы

Изменил, добавил или удалил исходник `src/**/*.md` (вне `src/en/` и `src/.vuepress/`) — в том же PR обнови перевод для каждого изменённого пути относительно `src/`:

`LLM_BASE_URL=… LLM_MODEL=… LLM_API_KEY=… node scripts/translate.mjs --only <путь>`

Затем проверь `node scripts/translate.mjs --check`. Для перевода нужны Node.js 20 и `npm ci`; проверка работает без зависимостей и сети. Все три LLM-переменные обязательны. В PowerShell задай их через `$env:LLM_BASE_URL`, `$env:LLM_MODEL`, `$env:LLM_API_KEY` перед запуском команды.

Репозиторий публичный: ключи и адреса LLM в репозиторий и в PR не писать. Ручные правки `src/en/**` перезапишутся при следующем изменении исходника (или `--force`); сохраняй `source_hash` и `{#id}` заголовков.

Русские страницы остаются в `/`, английские — в `/en/`. Обычный запуск обходит `TARGET_LOCALES` из `scripts/translate-lib.mjs`, обновляет устаревшие переводы и удаляет лишние. `--only` ограничивает и перевод, и удаление; `--locale en` выбирает локаль. Frontmatter переводится только для `title`, `shortTitle`, `description`, `tag`, `category`.

CI только мягко проверяет исходники, изменённые в PR: предупреждения и таблица в summary. Перевод приносит автор PR.
